# 62. Elemento não carrega estilo; a restrição migra para a cardinalidade no menu de adicionar

Sem contenção o Observatório vira sugestão. O autor escolhe *que* elemento usar, nunca *como* ele se parece, e o que sobrou de escolha é geometria fechada de dois ou três valores — nunca um slider.

## Alternativas consideradas

Expor tamanho, cor ou peso por elemento, já que a composição ficou livre.
