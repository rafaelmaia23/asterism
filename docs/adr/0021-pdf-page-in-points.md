# 21. Página do PDF em pt, 1080×1350

Confirma a §10. O bitmap é 2160×2700 nos dois casos, então a diferença é só o número que o visualizador mostra; e a unidade `px` do jsPDF depende de uma conversão de 96 dpi que não vale a pena carregar.

## Alternativas consideradas

Unidade `px` casada com a medida do canvas.
