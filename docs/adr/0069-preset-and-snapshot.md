# 69. Preset guarda o esqueleto e snapshot guarda o texto, separados por uma caixa de seleção ao salvar; os dez de seed são fixos

Uma caixa resolve os dois usos sem inventar vocabulário. Os dez de seed são o vínculo entre a §11 do documento de elementos e o código — editáveis, divergiriam do documento no primeiro ajuste e a Regra 2 ficaria sem chão.

## Alternativas consideradas

Dois conceitos na interface; ou um só, sempre com o texto.
