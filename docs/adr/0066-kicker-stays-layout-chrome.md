# 66. O `kicker` continua cromo do layout, e é a única peça de conteúdo que mora lá

Ele é o que a faixa do cabeçalho **é**, como a constelação é o que o rodapé é. Elemento traria cardinalidade a mais, migração a mais e uma faixa 80–148 que deixaria de ser fixa, para permitir uma etiqueta no meio do slide que ninguém pediu. Confirma a 42.

## Alternativas consideradas

Promovê-lo a elemento, posicionável em qualquer lugar da pilha.
